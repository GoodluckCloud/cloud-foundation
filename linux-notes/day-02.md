# Day 02 — Basic Terminal Commands & Rules

Today I learned my first terminal commands, package installation on Ubuntu, and a core rule of the Linux shell:

* **clear:** Clears previous text out of the terminal view to keep a clean workspace.
* **date:** Displays the current system date and time.
* **ncal:** Displays a calendar in the terminal with days arranged vertically (highlighting the current day). It was not pre-installed on my Ubuntu system (command not found), so I installed it using sudo apt install ncal.
* **cal:** Displays a standard calendar in the terminal with days arranged horizontally (highlighting the current day).
* Case sensitivity: Linux commands are strictly case-sensitive—typing Date or CLEAR will fail because the shell treats uppercase and lowercase letters as completely different characters.
